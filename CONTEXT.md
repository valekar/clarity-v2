# Workspace contract

**Input:** the user's V2 discussion, existing Clarity source as read-only evidence,
the supplied Flask ScanLink source and verified upstream documentation.

**Process:** maintain one explicit V2 plan; implement only subsequently authorized
increments; preserve the existing application; distinguish proposed, implemented,
tested and deployed behavior.

**Output:** [plan](docs/01-final-clarity-v2-plan.md), source-grounded research,
[ICM map](map/AGENTS.md), four app shells and initial shared UI/config packages.
Clinical services, authentication and data storage are still future work.

**Human check:** review the plan's assumptions and external inputs before enabling
the affected implementation or release. Ordinary authorized documentation work
does not require an additional confirmation.

The ICM form is a system map over this editable project, with decision/session
records for continuity. The foundation shell is live; proposed clinical runtime
remains ghost/stub until source and evidence support it.
