# Research contract

Input: explicitly relevant V1/ScanLink source and primary upstream documentation.
Process: distinguish observed code, observed UI, source claims and design inference.
Output: [reuse assessment](reuse-assessment.md) and [Hanko research](hanko.md).
Human check: unresolved provider/device assumptions remain release gates.

Do not copy clinical records, credentials or token-bearing portal URLs here.
All web research is dated; implementation pins versions and repeats compatibility
checks rather than assuming mutable upstream documentation is a release guarantee.
