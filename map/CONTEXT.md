# Map contract

Inputs: [active plan](../docs/ACTIVE.md), inspected source and actual evidence.
Read the catalog, then one relevant card and its citation. Code owns behaviour;
the plan owns proposed design. This map routes knowledge and records decisions.

Outputs: object/process cards, decisions and dated sessions; generated catalogs
and routing twins. Use [_meta/schema.md](_meta/schema.md) and copy a template.
Review: source citations resolve, runtime status is honest, change impact is
first-order, and sensitive clinical data/credentials never enter records.

No external consumers of this newly created path are known. If automation, an
issue or another repository starts referencing it, record that incoming dependency
on the relevant card before later renames. Never perform an unbounded home scan.
